# 🔧 Диагностические скрипты BionicPRO

Эта папка содержит автоматические диагностические инструменты для быстрого тестирования и устранения проблем системы BionicPRO.

## 📋 Доступные скрипты

| Скрипт | Назначение | Время выполнения | Детализация |
|--------|------------|------------------|-------------|
| `test-services.bat` | Быстрый тест endpoints | ~30 секунд | Базовая |
| `quick-health-check.bat` | Краткая диагностика + статистика | ~1 минута | Средняя |
| `health-check-full.bat` | Полная проверка системы | ~3 минуты | Высокая |
| `troubleshoot-check.bat` | Диагностика проблем + решения | ~2 минуты | Экспертная |

## 🚀 Использование

### Запуск из корневой директории проекта:
```bash
# Быстрый тест
checks\test-services.bat

# Краткая диагностика
checks\quick-health-check.bat

# Полная диагностика
checks\health-check-full.bat

# Устранение проблем
checks\troubleshoot-check.bat
```

### Запуск из папки checks:
```bash
cd checks

# Любой из скриптов
test-services.bat
quick-health-check.bat
health-check-full.bat
troubleshoot-check.bat
```

## 📊 Описание скриптов

### 🏃 `test-services.bat` - Быстрый тест сервисов
**Что проверяется:**
- ✅ Keycloak (http://localhost:8080/realms/reports-realm)
- ✅ Airflow (http://localhost:8081/health)
- ✅ ClickHouse (http://localhost:8123/ping)
- ✅ Frontend (http://localhost:3000)
- ✅ Reports API (http://localhost:5000/health)

**Результат:** Простые ✓/✗ индикаторы для каждого сервиса

### 📈 `quick-health-check.bat` - Краткая диагностика
**Что включено:**
- ✅ Тест endpoints с таймаутом 5 секунд
- ✅ Статус Docker контейнеров в табличном формате
- ✅ Подсчет успешных/неудачных тестов
- ✅ Итоговая сводка состояния системы
- ✅ Быстрые ссылки для доступа к сервисам

### 🔬 `health-check-full.bat` - Полная диагностика
**Что включено:**
- ✅ **Endpoints (3.1):** Детальная проверка с ответами сервисов
- ✅ **Контейнеры (3.2):** Статус + последние 10 строк логов каждого сервиса
- ✅ **Базы данных (3.3):**
  - ClickHouse: список баз данных
  - PostgreSQL (Airflow): список таблиц
  - PostgreSQL (Keycloak): список таблиц
  - Redis: ping + информация о версии
- ✅ **Система:** Docker volumes, networks, disk usage
- ✅ **Сводка:** Все критические URL для доступа

### 🛠️ `troubleshoot-check.bat` - Диагностика проблем
**Что проверяется:**
- ✅ **Порты:** Проверка занятости портов 3000, 5000, 5433, 5434, 6380, 8080, 8081, 8123, 9000, 9092
- ✅ **Ресурсы:** Доступная память и дисковое пространство
- ✅ **Docker сети:** Существование сетей bionicpro
- ✅ **Переменные окружения:** Валидация критических переменных в .env
  - JWT_SECRET_KEY
  - POSTGRES_PASSWORD
  - AIRFLOW_UID
- ✅ **Контейнеры:** Поиск нездоровых (unhealthy/Exit) контейнеров
- ✅ **Директории:** Проверка обязательных папок (logs, dags, plugins)
- ✅ **Предложения решений:** Автоматические рекомендации по исправлению

## 🔄 Рекомендуемая последовательность

### Ежедневное использование:
1. **Быстрая проверка:** `checks\quick-health-check.bat`
2. Если есть проблемы → **Полная диагностика:** `checks\health-check-full.bat`
3. Если нужно решение → **Устранение проблем:** `checks\troubleshoot-check.bat`

### При возникновении ошибок:
1. **Диагностика проблем:** `checks\troubleshoot-check.bat` (ПЕРВЫЙ ШАГ)
2. **Полная диагностика:** `checks\health-check-full.bat`
3. **Применение решений** из troubleshoot-check
4. **Проверка результата:** `checks\quick-health-check.bat`

### При первом запуске системы:
1. **Устранение проблем:** `checks\troubleshoot-check.bat` (проверить .env, порты, ресурсы)
2. **Запуск:** `docker-compose up -d`
3. **Ожидание:** 3-5 минут
4. **Проверка:** `checks\quick-health-check.bat`

## ⚡ Требования

- **ОС:** Windows 10/11
- **Команды:** curl (встроен в Windows 10+)
- **Docker:** Docker Desktop запущен
- **Расположение:** Автоматически определяется (можно запускать из любой папки)
